# Audio

Sounds used by the XMB menu.

- `sfx/` – short UI sounds (cursor move, confirm, back, error, launch)
- `music/` – background music / ambient loops

Suggested file names (so the menu code can find them):

| File | Plays when |
|------|-----------|
| `sfx/move.ogg` | moving the cursor between items |
| `sfx/confirm.ogg` | selecting an item |
| `sfx/back.ogg` | going back / closing a menu |
| `sfx/error.ogg` | an action fails |
| `sfx/boot.ogg` | the launcher starts |
| `music/bgm.ogg` | background loop on the main menu |

Prefer `.ogg` (small, loops cleanly on Android / Fire TV); `.mp3` also works.
Only use audio you made yourself or have the rights to.
